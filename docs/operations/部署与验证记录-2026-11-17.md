## 2. 部署步骤（实际执行）

```bash
docker compose --profile app build                    # 7 个镜像
docker compose --profile app run --rm --no-deps migrate
docker compose --profile app up -d --force-recreate
```

`up -d --force-recreate` 是刻意的：`up -d` 只在容器配置变化时重建，
**镜像更新了也不会 recreate**（本轮实测踩过两次，已写入最终报告 §6.1）。
