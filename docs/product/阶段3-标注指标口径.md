## 0. 通用规则

1. 每个指标必须带：名称、定义、公式、分子、分母、周期、来源、Owner、更新频率、口径版本、缺失语义。
2. 缺失数据不得显示为 `0`：区分 `0`（真实为零）、`N/A`（不适用/分母为 0）、`Unknown`（来源不可达）、`Stale`（超更新周期）、`Partial`（部分数据缺失）。
3. 真实值、估算值、待验证值分开；合成/Mock 数据默认不计入真实分母，必须显式过滤。
4. 指标口径变更必须版本化，并同步看板、明细、验收与 Owner。
5. IAA/黄金集等质量指标不得用于惩罚性个人排名；个人工作量仅授权角色可见。
6. 时间周期默认按业务日/周/月，时区与边界（左闭右开）需用户确认；未确认前标 `未验证`。

## 3. 口径与展示要求

1. 每个指标卡片显示：名称、口径版本、统计范围、更新时间、来源、Owner、缺失语义。
2. 支持按项目、任务、批次、场景、动作、机器人、标签、标注员（授权范围内）、日期范围筛选；不支持跨项目聚合。
3. 分母为 0 显示 `N/A`；来源不可达显示 `Unknown`；部分缺失显示 `Partial`；超过更新周期显示 `Stale`；真实为零显示 `0`。
4. 样例/Mock 数据默认过滤；样例视图必须显式开启并标注。
5. 指标与明细必须可核对；无法核对时不得上线为正式指标。
6. IAA/黄金集/抽检指标必须带样本量；样本量不足不得给出确定性结论。
7. 个人工作量与质量仅本人/AM/PM/AU 可见；不得用于未批准的绩效排名或惩罚。
