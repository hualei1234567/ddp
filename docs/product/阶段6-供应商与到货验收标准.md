## 0. 使用规则

1. 每条验收采用 Given / When / Then，可由第三方复现。
2. 证据优先级：自动化测试 > 真实请求/响应 > 数据库记录 > 审计账本 > 截图 > 说明。
3. 未执行标 `NOT RUN`；环境阻塞标 `BLOCKED`；缺真实证据标 `未验证`。
4. 合成数据必须标 `[SYNTHETIC]`，不得冒充真实供应商交付。
5. 缺陷等级：S1 越权/跨项目泄漏/账本被改写/放行伪造；S2 主链路不可完成；S3 局部错误；S4 文案。

## 1. 供应商档案

### AC-SUP-01 创建与项目隔离
Given 项目 A 的 Editor；When 创建供应商；Then 201 且 `project_id=A`、`status=DRAFT`；
项目 B 成员读取返回 403/404。

### AC-SUP-02 编码唯一
Given 项目 A 已有 `code=S-001`；When 再次创建同编码；Then 409 `duplicate_resource`。

### AC-SUP-03 状态机
Given `DRAFT`；When `activate`；Then `ACTIVE`；`TERMINATED` 后任何动作 → 409
`supplier_state_invalid`。

## 2. 到货批次

### AC-BAT-01 批次引用供应商
Given 供应商 `SUSPENDED`/`TERMINATED`；When 创建批次；Then 409 `supplier_not_active`。

### AC-BAT-02 跨项目供应商
Given 项目 B 的 supplier_id；When 项目 A 创建批次；Then 404 `resource_not_found`。

### AC-BAT-03 终审判定
Given 全部片段 `ACCEPTED`；When 终审；Then `ACCEPTED`；
存在 `NEED_MORE` → 409 `batch_review_incomplete`；
混合通过 → `PARTIALLY_ACCEPTED`；全部拒收 → `REJECTED`。

### AC-BAT-04 终审门禁（RawAsset）
Given 有 `ACCEPTED` 片段但无 `raw_asset_id`；When 终审；Then 422
`segment_raw_asset_missing`。

## 3. 片段裁决

### AC-SEG-01 裁决前置
Given 批次不是 `SCREENING`；When 裁决片段；Then 409 `batch_not_screening`。

### AC-SEG-02 原因必填
When 裁决 `REJECTED` 或 `NEED_MORE` 且无原因；Then 422 `decision_reason_required`。

### AC-SEG-03 职责分离
Given 片段登记人；When 同一人裁决；Then 403 `segment_decision_forbidden`。

### AC-SEG-04 终态
Given 片段 `ACCEPTED`；When 再次裁决；Then 409 `segment_terminal`。

## 4. 核验账本

### AC-LED-01 只追加
Given 任意裁决成功；Then 账本新增一条；无任何更新/删除端点。

### AC-LED-02 数据库禁改
Given 账本行已存在；When 直接 `UPDATE`/`DELETE`；Then 数据库触发器拒绝。

### AC-LED-03 可追溯
Given 一条账本记录；Then 含 `resource_id`、`action`、`from_status`、`to_status`、
`actor`、`request_id`、`occurred_at`。

## 5. 绩效指标

### AC-KPI-01 缺失不显示 0
Given 供应商无已终审批次；When 查询绩效；Then 一次通过率为 `null`，前端显示「暂无」。

### AC-KPI-02 计算正确
Given 2 个批次（1 准时、1 延期；均一次通过）；Then 及时率 0.5、一次通过率 1.0。

## 6. 前端

### AC-UI-01 页面状态
供应商/批次/片段/账本页面覆盖 Loading/Empty/Error/Forbidden/Partial/Stale/Disabled。

### AC-UI-02 动作渲染
裁决与终审按钮只按 `allowed_actions` 渲染。

### AC-UI-03 片段审片
片段页展示画面区、诊断快照、任务与手部交互概览、裁决区；诊断字段只读。
