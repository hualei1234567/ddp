## 0. 使用规则

1. 每条验收采用 Given / When / Then，必须可被第三方复现。
2. 证据优先级：自动化测试 > 请求/响应 > 数据库/对象存储记录 > 审计日志 > 人工截图 > 口头说明。
3. 人工截图不能单独证明权限、项目隔离、职责分离、黄金集防泄漏、幂等、不可变与审计属性。
4. 未执行标 `NOT RUN`；环境/人员阻塞标 `BLOCKED`；缺少真实证据标 `未验证`；不得用「应该可以」代替结果。
5. 未跑测试不得声称通过；不得为让测试变绿而放宽断言、删除用例或跳过安全测试。
6. 使用 Mock/合成/注入数据必须标 `[MOCK]` 或 `[SYNTHETIC]`，写明替代范围与未验证项。
7. 每条验收附测试名、命令、请求/响应、对象 ID、request_id、错误码或证据路径；无证据视为未通过。
8. 缺陷等级：S1 数据丢失/越权/跨项目泄漏/状态损坏/审计缺失；S2 主链路无法完成且无绕行；S3 局部错误/提示不清；S4 文案/布局。

## 4. 阶段门禁

- S1 阻断必须修复，阶段不得退出。
