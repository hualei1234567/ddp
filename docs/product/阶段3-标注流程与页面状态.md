> 边界：本文只定义业务流程、页面状态与异常路径，不定义技术实现与视觉稿。

## 1. 主流程

```text
Episode 验收（ACCEPTED/COMPLETED）
  → 样本选择（筛选/预览/去重/分层/快照）
  → Schema 发布（定义/审批/发布/快照）
  → 任务创建/审批（绑定样本集与 Schema）
  → 批次拆分/分配（容量/职责分离/领取）
  → 标注工作台（草稿/标注/证据/提交校验）
  → 提交（版本冻结）
  → 复核（通过/驳回/升级）
      ├─ 通过 → 黄金集/IAA/抽检 → 任务验收/完成
      ├─ 驳回 → 返工 → 新提交 → 复检
      └─ 升级 → 仲裁 → 通过/驳回/返工
  → 审计/outbox/血缘
```

## 2. 关键异常路径

| 场景 | 页面表现 | 系统行为 | 禁止 |
|---|---|---|---|
| Episode 不可标注 | Disabled + 原因 | 拒绝加入样本集，记录理由 | 静默纳入或显示 0 |
| 样本去重冲突 | 提示重复谱系 | 按 `episode_lineage_id` 去重；显式允许片段 | 重复计量 |
| Schema 已发布被修改 | Disabled | 409 `annotation_schema_immutable`，引导新版本 | 原地覆盖 |
| 提交缺必填 | 字段级错误 | 阻止提交，保留草稿 | 只弹窗无定位 |
| Schema 快照不一致 | Failed/Conflict | 422 `annotation_schema_snapshot_mismatch` | 用最新 Schema 静默替换 |
| 提交后编辑 | Disabled | 409 `annotation_submission_not_editable`，引导修订 | 覆盖旧版本 |
| 自审/自仲裁 | Forbidden | 403 职责分离违规，写审计 | 前端隐藏代替后端 |
| 分配超容量 | Disabled/Conflict | 409 `annotation_assignment_capacity_exceeded` | 部分写入 |
| 领取已过期/撤销 | Failed | 410/409，提示重新分配 | 静默失败 |
| 复核人占位并发 | Conflict | 乐观锁冲突，保留输入，要求刷新 | 覆盖他人结论 |
| 仲裁人数不足 | Disabled | 422 `annotation_arbitration_quorum_not_met` | 强行出结论 |
| 黄金集答案访问 | Forbidden | 403 `gold_set_access_denied`，写审计 | 返回脱敏字段 |
| IAA 样本不足 | Partial/Empty | 状态 `INSUFFICIENT_DATA`，值 `N/A` | 显示 0 |
| 抽检不通过 | Failed | 生成返工/仲裁要求 | 无结论关闭 |
| 跨项目访问 | Forbidden | 404/403，不泄漏存在性 | 返回对象名称 |
| 审计/outbox 失败 | Failed | 业务事务回滚，告警 | 状态已变审计缺失 |

## 3. 页面状态细则

### P-31 标签 Schema 管理

- Loading：Schema 列表/详情骨架；不显示旧版本冒充新版本。
- Empty：无 Schema 时显示创建入口；筛选无结果时显示清除筛选。
- Error：错误码、request_id、重试；不显示空白页。
- Forbidden：AN 无权编辑；不泄漏 `GOLD_ONLY/SYSTEM_ONLY` 标签。
- Partial：部分标签定义缺失时显示缺失范围，禁止发布。
- Stale：Schema 版本过期或任务引用旧版本时提示。
- Disabled：已发布 Schema 编辑按钮禁用并说明「创建新版本」。
- Pending：发布/废弃异步校验中显示状态。
- Success：发布成功显示版本、Hash、生效范围。
- Failed：校验失败逐项定位；发布失败保留草稿。

### P-32 样本选择与任务创建

- 预览必须显示候选数、入选数、排除数、去重数、分层统计与排除理由。
- 空样本禁止创建任务；不可标注 Episode 禁用并说明。
- 快照后显示 Hash 与不可变提示；变更引导新建样本集。
- 任务创建缺 Schema/样本集/目标/策略时字段级拒绝。
- 冲突：样本集被其他任务使用/作废时显示 Conflict 并保留输入。

### P-33/P-34 任务、批次与工作量

- 动作按钮基于服务端 `allowed_actions`；禁用显示原因。
- 非法状态迁移不改变页面状态，显示 409 与可执行动作。
- 分配冲突显示对象、时段、容量；不允许部分写入。
- 工作量缺失区分 0/N/A/Unknown/Stale/Partial；个人明细仅授权可见。
- 超容量需 AM 审批并记录原因。

### P-35 标注工作台

- 首屏：任务、分配、Schema 版本、截止时间、主操作；主操作路径尽量短。
- 草稿：自动保存并显示保存状态；刷新/断网恢复；冲突保留本地草稿。
- 表单：必填、类型、枚举、范围、时间片段、动作片段、语言、场景、证据。
- 提交：逐项校验；未完成禁用并定位；提交后显示「已提交，等待复核」。
- 返工：要求置顶，含问题、范围、责任人、截止时间；旧版本可查。
- 禁止显示黄金集答案、他人结果、他人草稿、跨项目信息。
- 错误提示四要素：发生了什么、可能原因、用户可以做什么、错误码/request_id。

### P-36 复核工作台

- 显示提交版本、Schema 快照、记录摘要、问题定位、历史复核。
- 通过需勾选检查项；驳回需问题码/严重级别/定位/原因；升级需理由。
- 自审 403；并发复核 Conflict；不得显示黄金集答案（除非 QI 授权）。
- 提交被抽检/仲裁时显示状态与下一步。

### P-37 仲裁工作台

- 显示触发原因、原复核、证据、投票、法定人数、回避状态。
- 仲裁人不得是标注人或首轮复核人；利益冲突可回避并重新分配。
- 结论必须选择通过/驳回/返工并填写理由；人数不足禁用提交。
- 结论写审计与血缘；不得修改原提交。

### P-38 黄金集管理

- 答案默认脱敏/折叠；AN/AE/RO 访问 Forbidden；访问写审计。
- 显示 Schema 兼容性、条目、难度、权重、轮换与暴露上限。
- 黄金集发布后条目不可原地修改；变更创建新版本。
- 准确率显示分子/分母/样本量；样本不足 N/A。

### P-39 IAA 报告

- 显示指标、标签、分子/分母、样本量、状态、计算版本、时间。
- `INSUFFICIENT_DATA` 显示 N/A 与原因；不得显示 0。
- 支持按标签/场景/任务下钻；不显示惩罚性个人排名。
- 计算中显示 Pending；失败显示错误码与重试；过期显示 Stale。

### P-40 质检抽检

- 显示抽样策略版本、抽样理由、分层、复核人、截止时间。
- 通过/不通过/转仲裁/返工闭环；不通过必须给问题项。
- 标注员不能自选抽检样本；抽检人不得是标注人。
- 缺失抽检结论显示 Pending/Partial，不得默认通过。

### P-41 审计与血缘

- 审计只读、不可删除；显示 actor、动作、前后值、原因、request_id。
- 血缘正反向、深度 1–5、分页；跨项目节点不可见。
- 加载失败显示 Error；部分节点缺失显示 Partial 并说明影响。
- 过期血缘/缓存显示 Stale。

## 4. 页面验收清单

- 每个页面覆盖 Loading/Empty/Error/Forbidden/Partial/Stale/Disabled/Pending/Success/Failed。
- 工作台、复核、仲裁额外覆盖 Conflict；工作台覆盖 Offline/草稿恢复。
- 所有错误提示含错误码与 request_id；所有禁用按钮有原因。
- 所有敏感字段按角色脱敏；所有写操作有审计；所有异步任务有 Pending/Failed。
- 页面不得用颜色作为唯一状态标识；不得用 Mock 数据冒充真实指标。
