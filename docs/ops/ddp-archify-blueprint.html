回滚策略、配额监控与排障入口

          

            
1. 前端秒级回滚：Cloudflare Dashboard → Workers & Pages → ddp-web → Deployments → 选中历史正常构建点击 Rollback to this deployment（全球边缘 30 秒内生效）。

            
2. 后端镜像与数据库回滚：遵循 docs/ops/backup-restore-runbook.md（MEM-OPS-001 7 个不变量），升级前先执行 pg_dump 快照；若应用异常则切回上一 Git tag 镜像并按需 alembic downgrade -1。

            
3. 免费额度重点监控：
              
    
                
  • CF Pages 构建次数：上限 500 次/月（建议仅在 main 分支开启自动生产构建，PR 按需预览）。
    • 
                
  • 若启用 Pages Functions：上限 10 万次/天；采用推荐的 api.ddp.online 子域直连则完全不消耗 Workers/Functions 配额。
    • 
                
  • 若启用 Cloudflare R2：上限 10 GB 存储 + 100 万次写 + 1000 万次读/月，可在 R2 Overview 设置用量告警。
    • 
              

            

            
4. 故障排查入口：请求响应头均携带 X-Request-Id（app/api/middleware/request_id.py），结合 docker compose logs -f api worker 按 request_id 精确检索领域异常原文；指标抓取见 GET /metrics（Prometheus + Alertmanager :9090/:9093）。
