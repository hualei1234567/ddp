# ADR-0005 对象存储与文件安全

- 状态：已提议（待用户批准）
- 日期：2026-11-08
- 关联：规范 §6.7、§17.1

## 背景

采集数据包含大体积视频、图片、MCAP/ROS bag、点云等，不能写入业务表。上传需要支持分片、
断点续传、幂等与恶意文件防护。

## 决策

- 使用 S3 兼容对象存储（本地 MinIO，生产可替换为云 OSS/S3）。
- 数据库只保存元数据、对象 Key、Hash、大小、格式、状态、权限、版本与血缘。
- 上传流程：申请上传会话 → 分片上传 → 完成校验（大小/类型/签名/Hash）→ 登记 RawAsset → 隔离区。
- 文件类型必须白名单 + 内容签名校验，不只依赖扩展名。
- 下载走短期签名 URL 或后端流式代理，必须审计。
- 对象路径按 `project_id/日期/资产ID` 隔离。

## 后果

- 需要维护对象存储生命周期、配额与清理策略。
- 上传失败/重复上传必须幂等，不能产生重复资产。
- 本地开发依赖 MinIO 容器。

## 替代方案

- 直接存本地文件系统：不利于横向扩展与权限隔离，否决。
- 二进制入库：违反规范，否决。
