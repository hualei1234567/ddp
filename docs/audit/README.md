## 审计约定

- **实测优先**：每条结论附可复现命令或文件路径，不引用自述文档作为证据
- **对抗性立场**：优先挖问题；评级为相对判断，不提供行业基准对标
- **诚实边界**：明确列出未覆盖项（SAST、渗透、覆盖率数字、长期运行数据）
- **可执行**：风险登记册每条都有责任人可选的"建议动作 + 时限"
