## 关键决策

1. 上传传输态（`UploadSession`）与资产态（`RawAsset`）分离；RawAsset 在完成时登记，初始 `VALIDATING`。
2. 分片预签名直传 + 分片确认 + `ListParts` 权威核对；整文件 Hash 异步校验；`complete` 返回 202。
3. RawAsset 内容不可变、按 `sha256+size_bytes` 内容寻址；重复上传通过 `raw_asset_links` 关联。
4. 隔离区为逻辑状态；放行双人审批并重新校验；墓碑双人审批、保留元数据与血缘。
5. Episode `READY` 冻结数据字段，修订创建新 `episode_version`；Manifest/标定快照/规则版本必须记录。
6. 血缘只追加；跨项目引用由投影表 + 复合外键/触发器阻断。
7. 所有阶段 2 表带 `project_id`；`If-Match` 乐观锁；状态迁移由领域动作 + DB 触发器双重兜底。
