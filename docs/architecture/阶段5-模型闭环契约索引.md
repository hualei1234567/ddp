## 3. 通用约束

- 所有项目路由服务端强制 `project_id`；跨项目 404/403。
- 写动作 `If-Match: "<version>"`；缺失 428，失配 409。
- 创建/动作支持 `Idempotency-Key`；同键不同请求体 409。
- 列表 `limit` 1–100 默认 20；支持 `cursor`。
- 错误体统一 `{"error": {"code", "message", "request_id", "details?"}}`。

## 4. 关键决策

| 决策 | 结论 |
|---|---|
| 模型权重托管 | 不做；只保存对象键、SHA256、大小与格式 |
| 推理执行 | 不在 DDP 执行；登记外部服务与任务，Adapter 回调回写状态/结果 |
| 评测结论 | PASS/FAIL/UNKNOWN；缺指标 = UNKNOWN，不得默认 PASS |
| 发布不可变 | `RELEASED` 版本内容不可改；变更创建新版本 |
| 反馈转需求 | 反馈置 `REQUIREMENT_CREATED` 并记录 `converted_requirement_id`；需求保留 `source_feedback_ids` |
| 需求满足 | 必须关联 FROZEN+VALID DatasetVersion；复测通过后可 CLOSED |
| 自动标注优化 | P1；P0 不自动改写标注结果 |
| 真实平台 | 未提供；P0 仅允许 `[MOCK]` Adapter，真实评测/推理 `BLOCKED` |
