## 3. 通用约束

### 3.1 项目隔离与分页

- 所有项目路由由服务端校验成员资格并强制 `project_id` 过滤；跨项目统一 404
  `resource_not_found`，不泄漏存在性。
- 列表统一 `limit` 1–100，默认 20；除策略列表外支持 `cursor`（游标分页）。
- 策略对象创建后不可原地修改；修改产生新 `version` 并重算 `policy_sha256`。

### 3.2 `If-Match` 与 `Idempotency-Key`

- 写动作（PATCH / actions）要求 `If-Match: "<version>"`；缺失 428
  `precondition_required`，失配 409 `version_conflict`。
- 创建与写动作支持 `Idempotency-Key`（≥8，≤128）；同键不同请求体 409
  `idempotency_key_reused`。
- Adapter 回调不要求 `If-Match`，使用 HMAC 签名 + 时间窗 + nonce + `event_id` 幂等。

### 3.3 响应与字段

- 响应对象以 `packages/contracts/schemas/*.json` 为唯一来源；请求 DTO 在
  `fragments/schemas.stage4.yaml`。
- 错误体统一 `{"error": {"code", "message", "request_id", "details?"}}`。
- 复杂响应字段（Manifest、LeakageReport、QualityReport、SelectionPreview）变更需版本化。

## 5. 状态机同步与实现差异

### 5.1 状态机

- Dataset：`DRAFT → ACTIVE → ARCHIVED`，`ARCHIVED → ACTIVE`（restore）。
- DatasetVersion：`DRAFT → BUILDING → VALIDATING → READY → FROZEN → SUPERSEDED/ARCHIVED`，
  以及 `VALIDATION_FAILED`、`CANCELLED`。
- ExportJob：`QUEUED → RUNNING → SUCCEEDED/FAILED/PARTIAL/CANCELLED`，`FAILED → QUEUED`（retry）。
- TrainingRequest / Revision / Delivery / Grant / ExternalReference：见
  `backend/app/domain/datasets/training_state_machines.py` 与
  `packages/contracts/schemas/state-machines.v1.json`。
- 数据库触发器（迁移 0019/0020）兜底状态迁移、内容不可变与禁删。

### 5.2 草案 → 冻结的差异（以代码事实为准）

| 项 | 草案 | 冻结 | 原因 |
|---|---|---|---|
| 资产目录 `/asset-catalog` | 有 | **不进入快照** | 未实现 |
| Dataset / TrainingRequest 血缘 | 有 | **不进入快照** | 未实现 |
| `PATCH .../versions/{version_id}` | 有 | **不进入快照** | 未实现 |
| 质量策略 `/quality-policies` | 无 | **新增 3 个操作** | 已实现 |
| 产物下载 `/artifacts/{path}/download` | 无 | **新增 1 个操作** | 已实现 |
| 策略路径参数 | `dedup_policy_id` 等 | `policy_id` | 与实现一致 |
| 策略列表 cursor | 有 | 无 | 实现未提供 |
| 请求 DTO 必填项 | 含默认字段必填 | 仅保留实现必填 | 避免客户端被过度约束 |
| DatasetVersion 动作响应 | 200 + 202 | 仅 200 | 实现同步返回 |
| 外部引用动作请求体 | `ActionRequest` | 无请求体 | 实现不读取 body |
| 回调动作请求体 | 声明 body | 保留 `AdapterCallbackPayload` | 实现按 body 验签与解析 |
