### 1.2 动作白名单（`allowed_actions` 由服务端下发）

| 资源族 | 非系统动作 |
|---|---|
| Model | `activate` / `deprecate` / `restore` / `archive` |
| ModelVersion | `validate` / `publish` / `deprecate` / `archive`（`return-draft` 允许从校验失败回到草稿） |
| Evaluation | `cancel`（完成、失败、取消后无动作） |
| InferenceService | `deploy` / `activate` / `stop` / `retire` / `reset` |
| InferenceTask | `cancel` |
| ModelFeedback | `triage` / `dismiss` / `create-requirement` / `resolve` |
| DataRequirement | `submit` / `approve` / `reject` / `plan` / `start` / `satisfy` / `link-retest` / `close` / `cancel` |

`system-start` / `system-succeed` / `system-fail` / `system-validate-pass` /
`system-validate-fail` / `system-deploy-fail` 只由服务端与已验签 Adapter 回调触发，
不会出现在 `allowed_actions` 中。

### 1.3 并发与幂等

- 写动作：`If-Match: "<version>"`；缺失 428，失配 409 `version_conflict`。
- 创建与动作：`Idempotency-Key` 可选；同键不同请求体 409 `idempotency_key_reused`。
- 回调：HMAC-SHA256(`timestamp.nonce.raw_body`)，时间窗默认 ±300 秒，
  nonce 防重放；`event_id` 相同但内容不同 409 `model_callback_replayed`。

## 3. 草案 → 冻结差异

| 项 | 草案 | 冻结（实现） | 原因 |
|---|---|---|---|
| 通用动作请求体 | `ActionRequest` | 重命名为 `ModelOpsActionRequest` | 全局 `ActionRequest` 属设备域，字段不同；避免同名冲突 |
| 回调载荷 | 未声明 `project_id` | 必填 `project_id` | `ModelAdapterCallbackPayload` 用于服务端项目隔离校验 |
| 回调非法请求 | `400 BadRequest` | `422 UnprocessableEntity` | 实现统一抛 `ValidationFailedError` |
| `ErrorEnvelope` / 公共参数 / 回调头 | 草案内联 | 复用全局组件 | 避免重复定义与漂移 |
| `evaluation_verdict_unknown` | 错误码存在 | 移除 | 缺阈值时结论为 `UNKNOWN` 属正常结果，不返回错误 |
| `released_by` | 已声明 | 保留 | 实现返回该字段，冻结补齐 |

未纳入冻结：自动标注优化（P1，未实现）、跨项目模型共享（未批准）、
真实评测/推理执行（外部平台未提供）。
