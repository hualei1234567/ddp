## 3. 通用约束

### 3.1 项目隔离与分页

- 所有路径均带 `{project_id}`；服务端校验成员资格并强制项目过滤。
  跨项目资源统一 404 `resource_not_found`；非成员 403 `forbidden`。
- `cursor` 不透明；非法游标 422 `validation_failed`；`limit` 默认 20、范围 1–100。
- `GET /annotation-schemas`、`/annotation-sample-sets`、`/annotation-tasks`、
  `/annotation-tasks/{task_id}/batches`、`/annotation-assignments`、`/gold-sets`
  返回 `{items, next_cursor}`。
- `GET /annotation-submissions`、`/annotation-submissions/{id}/records`、
  `/annotation-submissions/{id}/reviews`、`/annotation-submissions/{id}/arbitrations`、
  `/quality-samples`、`/iaa-reports` 当前不支持 cursor，`next_cursor` 恒为 `null`；
  其中提交/抽检/IAA 列表的 `task_id` 为**必填**查询参数。

### 3.2 `If-Match` 与 `Idempotency-Key`

| 端点组 | `If-Match` | `Idempotency-Key` |
|---|---|---|
| Schema PATCH 与 actions | **必填** | 可选 |
| 样本集 actions | **必填** | 可选 |
| 任务 PATCH 与 actions | **必填** | 可选 |
| 批次 PATCH 与 actions | **必填** | 可选 |
| 分配 actions | **必填** | 可选 |
| 提交 actions | **必填** | 可选 |
| 复核 actions | **必填** | 可选 |
| 仲裁 actions 与 votes | **必填** | 可选（votes 无幂等键） |
| 黄金集 actions | **必填** | 可选 |
| 抽检 actions | **必填** | 可选 |
| 所有创建端点 | 不要求 | 可选 |
| 黄金集 evaluations / injections | 不要求 | 不要求 |

- 缺失 `If-Match` → 428 `precondition_required`；格式非法 → 422 `validation_failed`；
  版本失配 → 409 `version_conflict`。
- 幂等键作用域 `(project_id, user_id, key)`，长度 8–128；同键不同请求体 →
  409 `idempotency_key_reused`。

### 3.3 响应与字段

- 错误体统一 `{"error": {"code", "message", "request_id", "details?"}}`。
- 响应对象 Schema 的字段与后端 DTO 一致，唯一来源为
  `packages/contracts/schemas/*.v1.schema.json`：
  - `QualitySample` 必含 `annotator_id`、`metadata`；
  - `GoldSet` 为脱敏视图（`items` 内不含 `expected_labels`），答案仅在
    `/gold-sets/{id}/answers` 返回；
  - `IAAReport` 在样本不足时 `status=INSUFFICIENT_DATA`，不以 0 冒充；
  - 分页包装统一 `{items, next_cursor}`。

## 9. 风险与回滚

- 风险：外部 JSON Schema 通过 `$ref` 引入，CI 必须保留整个 `packages/contracts`
  目录；仅打包 `openapi.yaml` 会解析失败。已用 Redocly bundle 验证解析。
- 风险：`schemas/*.json` 与后端 DTO 存在同步成本；本次由后端 Pydantic 模型直接生成，
  后续 DTO 变更必须同步 Schema 并重跑冻结检查。
- 风险：草案中未实现端点（工作量/血缘/指标）若被前端提前调用会 404；不得据草案
  声称可用。
- 风险：`If-Match` 在 OpenAPI 标记为必填，而框架层为避免 422 将其声明为可选；
  语义以 428/409 为准，与阶段 2 一致。
- 回滚点：本次仅修改 `packages/contracts/**`、`docs/**`，未改 `backend/**` 业务代码、
  未执行迁移/部署/数据操作。回滚只需还原上述文件与基线；旧阶段 2 基线不删除。
