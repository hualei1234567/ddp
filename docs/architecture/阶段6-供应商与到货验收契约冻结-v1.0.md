### 1.1 动作白名单

| 资源族 | 动作 |
|---|---|
| Supplier | `activate` / `suspend` / `resume` / `terminate`（不可逆） |
| DeliveryBatch | `dispatch` / `arrive` / `start-screening` / `finalize` / `rework` / `close` |
| InboundSegment | `queue-review` / `resubmit`，以及 `decision`（ACCEPT/REJECT/NEED_MORE） |

`system-*` 动作只由服务端内部触发，不出现在 `allowed_actions` 中。

### 1.2 并发与幂等

- 写动作：`If-Match: "<version>"`；缺失 428，失配 409 `version_conflict`。
- 创建与动作：`Idempotency-Key` 可选；同键不同请求体 409 `idempotency_key_reused`。
- 终审要求项目负责人权限；终态由片段统计计算，不接受客户端指定。

## 3. 草案 → 冻结差异

| 项 | 处理 |
|---|---|
| 路径参数 `BatchId` | 复用全局 `components.yaml#/parameters/BatchId`，不重复定义 |
| 动作参数 `BatchAction` | 全局同名参数属采集批次（取值不同），改名为 `InboundBatchAction` 避免语义覆盖 |
| 账本 `batch_id` | 允许 `null`：供应商级事件（登记/激活/终止）没有批次 |
| 供应商动作权限 | `activate/suspend/resume` 为常规写；`terminate` 要求项目负责人 |
