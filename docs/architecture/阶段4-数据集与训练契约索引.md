动作白名单：

- Dataset：`archive`、`restore`。
- DatasetVersion：`build`、`validate`、`return-draft`、`freeze`、`cancel`、`archive`、`reproduce`。
- DatasetGrant：`approve`、`reject`、`revoke`。
- ExportJob：`retry`、`cancel`。
- TrainingRequest：`block`、`unblock`、`cancel`、`close`。
- TrainingRequestRevision：`submit`、`approve`、`reject`。
- TrainingDelivery：`ready`、`deliver`、`accept`、`reject`、`rework`、`cancel`。
- ExternalTrainingReference：`sync`、`cancel`。

非法动作返回 422 `validation_failed`。

## 3. 通用约束

- 写动作 `If-Match`：缺失 428 `precondition_required`；格式非法 422 `validation_failed`；失配 409 `version_conflict`。
- 写动作支持 `Idempotency-Key`，作用域 `(project_id, user_id, key)`，至少 24h；同键不同请求体 409 `idempotency_key_reused`。
- 错误体统一 `{"error": {"code", "message", "request_id", "details?"}}`。
- 所有对象强制 `project_id`；跨项目统一 404/403，不泄漏存在性。
- 异步操作（构建/导出/外部提交）返回 202，不占用 HTTP 请求线程；Job 必须可查询、可重试/取消、有超时与失败记录。
- 审计只追加；outbox 与业务同事务；事件按 `event_id` 幂等。

## 4. 关键决策

1. **版本冻结**：DatasetVersion `FROZEN` 后样本、划分、Manifest、质量/泄漏报告与 Hash 不可变；变化创建新版本。
2. **输入门禁**：只接受 Episode `ACCEPTED/COMPLETED`、质量 `PASS/WARN`（WARN 需确认）、标注 `APPROVED`、Manifest 可校验、标定/时间同步有效、`usage_policy=TRAINING_ALLOWED`。
3. **去重**：精确规则 `episode_lineage/manifest_sha256/raw_asset_sha256`；近似重复默认 `WARN_ONLY`，不阻断。
4. **划分**：默认 Episode 级 80/10/10，可配置；确定性种子与舍入；空测试集默认失败。
5. **泄漏**：血缘/内容 Hash/相似簇跨划分硬规则；场景组/批次/时间重叠默认软规则；硬规则不可豁免，软规则 PO 审计豁免；`UNKNOWN` 失败关闭。
6. **LeRobot**：先冻结 `ddp.lerobot/1.0.0` 最小字段集 + sidecar；真实 Loader 验证前 `UNVERIFIED`，标 `未验证`。
7. **导出**：异步、幂等、超时/重试/取消；逐文件与汇总 SHA256；`PARTIAL` 不是成功。
8. **训练需求**：批准后不可原地修改；变更创建新 revision 并重新审批；提交人不得自批。
9. **交付**：必须引用 APPROVED revision、FROZEN 有效版本、SUCCEEDED 且校验通过的 ExportJob；创建人不得是唯一验收人。
10. **授权**：默认禁止跨项目；DatasetGrant 由 PO 审批，带范围/到期/原因/撤销，到期/撤销立即生效。
11. **Adapter**：HMAC-SHA256 + 时间窗 + nonce + 幂等键 + 重放防护；不支持能力显式 Unsupported；DDP 不建训练集群。
12. **血缘**：节点/边只追加；跨项目/成环拒绝；`SUPERSEDES` 线性；失效追加 `INVALIDATES`。
