## 1. 结论

1. 契约冻结 v1 与 ADR-0009 已批准并生效，字段、状态机、错误码、参数 Schema 为唯一设计基线。
2. 当前代码是**部分实现**：Device/Sensor/Calibration 基础 CRUD、状态动作、乐观锁、项目隔离、四眼校验和已存在；但冻结目标中的版本三元分离、Profile 目标与版本谱系、Sensor 坐标系、审计/outbox、DB 兜底、`revise`、幂等与 UUIDv7 尚未实现。

## 4. 关闭门禁

任一 `G-xx` 关闭必须同时满足：

1. 代码、迁移、契约三处命名一致；破坏性变更走 ADR。
2. 有真实测试证据：单元/接口/契约/PostgreSQL 集成；SQLite 结果不作为 DB 兜底验收。
3. 跨项目与越权负向用例通过；不允许以“应用层已校验”替代 DB 兜底。
4. OpenAPI 与 FastAPI 导出、前端生成类型无意外 diff；CI 的 lint/兼容性检查为绿。
5. 冻结字段未实现时不得在对外契约中标记为可用；`0.2.0` 与 `1.0.0` 的差异必须在本文可追溯。
6. 迁移、部署、发布、删除数据仍按项目铁律单独批准。
