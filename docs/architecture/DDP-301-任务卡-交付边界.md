## API/Schema 约束

- HTTP 主版本 `/api/v1`；项目资源统一 `/api/v1/projects/{project_id}/...`；服务端强制项目范围，不信任客户端 `project_id`。
- 写动作必须 `If-Match: "<version>"`；缺失 428 `precondition_required`，失配 409 `version_conflict`。
- 幂等键 `Idempotency-Key` 作用域 `(project_id, user_id, key)`，至少 24h；同键不同体 409 `idempotency_key_reused`。
- 上传完成 `POST .../complete` 返回 `202`；整文件 SHA256/格式/扫描由 `VALIDATE` Job 异步完成。
- RawAsset 内容字段不可变；Episode `READY` 起冻结数据字段；修订创建新 `episode_version`。
- 状态只经具名动作迁移；禁止通用 `PATCH status`；非法迁移 409 `state_transition_invalid`。
- 错误体沿用 `ErrorEnvelope`；错误码以 `contract-draft/collection/error-codes.v1.json` 为准。
- 复杂 Schema 以 `contract-draft/collection/*.schema.json` 为准；OpenAPI 通过相对 `$ref` 引用。
