## 2. 核心页面

### 工作台
显示下一步待办而不是只堆 KPI：待执行采集、上传失败、解析失败、待分配标注、我的待办、待审核、返工、Dataset 可冻结、Export 失败。

### 采集中心
Task 列表、设备要求、SOP、Session、Agent 状态、上传状态。

### 上传中心
列表和详情页展示每个文件的进度、Hash、校验、重试、隔离原因。

### Episode Explorer
支持 Project / CollectionTask / Session / Robot / Device / Status / Quality / Annotation 状态筛选。

### 标注任务管理
创建 Batch、选择 Episode、选择 Spec、指定 Annotator、查看负载和进度。

### 标注控制台
使用 `08_标注控制台PRD_UIUX与交互实现.md` 的三栏布局。

### 质量中心
自动 QC、人工审核、返工、仲裁和问题定位。

### Dataset Builder
候选样本、门禁原因、分布、split、冻结和导出。

## 3. 设计原则

状态、任务、下一步动作优先；保持当前 Ant Design 视觉体系；视频和时间轴是标注主工作区，不被 KPI 卡片挤压；右侧 Inspector 保持上下文；空状态、加载、部分成功、失败、无权限、过期状态统一；批量操作有影响预览；高风险动作确认；不使用静态 Mock 数据冒充真实结果。

## 4. 复用组件

优先复用 PageContainer、PageState、ApiErrorState、ProjectScopeRequired、IdentifierValue、useRequest、useCursorPage、AntD Table / Form / Drawer / Modal，以及现有 API Client。

## 5. 必须补齐的前端交互测试

现有审计指出部分组件测试仅静态渲染。V3.1 新增控制台必须覆盖真实点击、异步保存、时间轴操作、表单校验、权限、错误和并发冲突。引入测试库需先做依赖评估和 ADR。
