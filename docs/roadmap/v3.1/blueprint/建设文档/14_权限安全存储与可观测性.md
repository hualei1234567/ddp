# 权限、安全、存储与可观测性实施规范

## 1. 权限矩阵

| 能力 | Admin | Project Owner | Collector | Annotator | Reviewer | Algorithm User |
|---|---|---|---|---|---|---|
| 设备登记 | 全局/授权范围 | 项目内查看 | 查看分配设备 | 无 | 查看 | 无 |
| CollectionTask | 管理 | 管理 | 执行分配任务 | 无 | 查看 | 查看 |
| CaptureSession | 查看/管理 | 查看 | 创建/结束自己的 | 无 | 查看 | 无 |
| RawAsset | 授权访问 | 项目内查看 | 查看上传结果 | 被分配 Episode | 审核范围 | 只读授权 |
| AnnotationTask | 管理 | 创建/分配 | 无 | 只操作分配项 | 查看 | 无 |
| AnnotationResult | 管理 | 查看 | 无 | 编辑自己的草稿 | 审核/只读 | 只读已发布 |
| Review | 管理 | 查看 | 无 | 查看反馈 | 执行审核 | 无 |
| Dataset | 全局/授权 | 创建/冻结 | 无 | 无 | 查看 | 查看/导出授权 |

最终角色名与现有 ROLE_PERMISSIONS 对齐。必须在后端强制校验，前端隐藏按钮不构成权限。

## 2. ProjectScope

所有资源查询必须绑定 ProjectScope：CaptureSession 继承 CollectionTask 的 Project；RawAsset 继承 CaptureSession 的 Project；Episode 继承 RawAsset/Session 的 Project；AnnotationTask 只能分配同 ProjectScope 的用户；DatasetItem 只能引用同 ProjectScope 资产；跨项目引用必须显式授权并审计。

## 3. Edge Agent 身份

Agent 有独立身份和撤销能力；Agent 仅能访问被授权 Project / Device / CollectionTask；凭据不写入 Manifest；设备 Token 不与用户 JWT 混用；TLS；上传授权短时有效；设备注册、轮换、撤销均审计。

## 4. 数据安全

Raw 对象不可被处理流程覆盖；MinIO Bucket/Prefix 权限最小化；下载 URL 短时签名；上传文件做 MIME + magic bytes + size + hash 校验；防止路径穿越；文件名不作为对象授权依据；日志不得记录 Token、签名 URL、敏感序列号；需要对人体视频做隐私审查时，按项目要求增加脱敏流程，不默认改变原始数据。

## 5. 数据保留

Raw、Processed、Annotation、Dataset Export 使用不同保留策略；清理前检查是否被 DatasetVersion / TrainingRequest 引用；Frozen Dataset 关联的依赖资产不得静默删除；清理操作需审计、预览和确认。

## 6. 可观测性

统一关联字段：`request_id / trace_id / project_id / collection_task_id / capture_session_id / upload_session_id / raw_asset_id / processing_run_id / episode_id / annotation_task_id / dataset_version_id`。

监控 Agent last_seen、CaptureSession interrupted、Upload throughput/failure/resume、Ingestion queue lag、Processing duration/failure、Annotation backlog/overdue、Save failure/conflict、Review turnaround、Dataset export failure 和 Storage usage。

## 7. 备份与恢复

PostgreSQL 和 MinIO 分开备份；验证对象引用与实际对象一致；进行恢复演练；恢复后验证 DatasetVersion Manifest 与 Hash；staging/production 环境未恢复时如实标记 BLOCKED。
