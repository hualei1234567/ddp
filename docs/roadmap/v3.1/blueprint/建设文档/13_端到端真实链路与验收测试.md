# V3.1 端到端真实链路与验收测试计划

## 1. 测试原则

必须同时验证既有 HF 公开数据链路回归、新增真实机器人/端侧文件采集链路、标注任务分配与控制台交互、质量审核与返工、Dataset Version 和导出。Mock 仅用于单元/契约测试，不可作为端到端真实链路验收证据。

## 2. E2E A：HF 回归链路

```text
HF Repo + pinned Revision
 → ImportJob → Download + SHA256 → LeRobot Adapter → MinIO
 → Episode / MediaAsset → Video Range Playback → AnnotationTask
 → Assignment → Annotation Console → Submit → QC / Review
 → DatasetVersion → Export
```

保留既有 NVIDIA `PhysicalAI-Human-1M-100K` 公开 preview 小样本回归，但不得下载 gated 全量数据。数据集 License、Revision 和授权状态需重新核验。

## 3. E2E B：真实端侧硬件/文件链路

```text
真实机器人/设备或真实导出文件
 → CollectionTask → CaptureSession → Edge Agent → Manifest
 → Local validation → Multipart upload → MinIO
 → RawAsset verification → Adapter / Pipeline → Episode
 → AnnotationTask → Assign specific annotator → Annotation Console
 → Submit → QC → Reviewer Accept → Dataset Builder
 → Freeze DatasetVersion → Export + checksum verify
```

若没有真实硬件，允许先使用由实际机器人导出的原始文件进行文件接入 Pilot，但验收报告必须标注 `HARDWARE_CAPTURE_NOT_TESTED`，不得写“端侧实时采集已通过”。

## 4. 必测异常场景

Edge Agent 断网、Agent 重启、上传中断、分片重复、URL 过期、Manifest 缺文件、SHA256 不匹配、同一 Session 重复提交、解析 Worker 崩溃、视频 Range 不支持、Annotation 自动保存失败、两个用户争抢同一任务、If-Match 冲突、Schema Version 不匹配、必填标签缺失、片段超出 Episode 时长、审核退回、返工后重新提交、Dataset Freeze 时发现未审核样本、导出中断、官方 Reader 无法读取导出包。

## 5. 最低验收标准

| 项 | 验收 |
|---|---|
| Capture | 至少 1 个真实 CaptureSession，绑定 CollectionTask 和设备 |
| Raw Upload | Manifest、文件数、总大小、SHA256 一致 |
| Resume | 中断后续传成功，不重复创建资产 |
| Parsing | 至少 3 个完整 Episode 进入 Canonical |
| Assignment | 至少 1 个 AnnotationTask 指定给具体 Annotator |
| Access Control | 非 assignee 无编辑权 |
| Annotation Console | 完成一条 Episode 标注、自动保存、提交 |
| QC | 至少触发一次规则通过和一次问题/返工路径 |
| Review | Reviewer 完成 Accept 或 Rework |
| Dataset | 只包含通过门禁的 Episode / Annotation Version |
| Freeze | DatasetVersion Manifest / Hash 可复核 |
| Export | 导出文件可回读，Hash 一致 |
| Lineage | 从 DatasetItem 追溯到 RawAsset / CaptureSession / CollectionTask |

## 6. 测试分层

Unit：状态机、Schema、Adapter、映射、规则；API：权限、幂等、If-Match、错误；Integration：PostgreSQL、MinIO、Outbox、Worker；Frontend interaction：真实 DOM 交互；E2E：完整真实链路；Recovery：弱网、重试、崩溃恢复；Security：ProjectScope、文件访问、设备身份；Performance：大文件、长视频、任务队列、分页。

## 7. 证据包

每次 E2E 保存 commit、环境版本、Dataset Repo/Revision 或硬件信息、Manifest、Upload log、SHA256 report、Processing log、Episode list、Assignment record、Annotation Result Version、QC/Review records、Dataset Manifest、Export checksums、截图/视频、测试命令和退出码。

## 8. 完成口径

`Code Complete`、`Test Passed`、`QA Accepted`、`User Accepted`、`Released` 分别记录。任何一项缺失不得宣称全链路完成。
