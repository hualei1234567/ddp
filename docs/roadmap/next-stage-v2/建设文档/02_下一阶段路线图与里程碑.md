# DDP 下一阶段路线图与里程碑

## 1. 里程碑总览

| 阶段 | 名称 | 优先级 | 核心产出 | 前置依赖 |
|---|---|---:|---|---|
| N0 | 现状审计与基线冻结 | P0 | 功能矩阵、差距清单、Backlog | 无 |
| N1 | HF 数据接入 MVP 固化 | P0 | 真实导入、解析、审看、审核、报告 | N0 |
| N2 | Canonical Schema 与 Adapter | P1 | 统一数据模型、多格式映射 | N0/N1 |
| N3 | 多模态 Pipeline 与 Episode | P1 | 可复现处理、同步、切片 | N2 |
| N4 | 标注与质量中心 | P1 | 标注、自动质检、人工复核、返工 | N2/N3 |
| N5 | 数据资产与 Dataset 生命周期 | P1 | 资产目录、版本、血缘、冻结、导出 | N2/N3/N4 |
| N6 | 训练集成与模型评测 | P2 | 训练数据交付、模型评测引用 | N5 |
| N7 | 模型反馈闭环 | P2 | 数据缺口分析、新需求 | N6 |
| N8 | 真实采集与设备集成 | P2 | 真实设备数据进入标准链路 | N2/N3 |
| N9 | 规模化运营与企业治理 | P3 | 多基地、多供应商、经营与治理 | N4/N5/N8 |

阶段可按实际依赖并行拆分，但共享 Schema、数据库 Migration、权限和公共 API 必须指定唯一 Owner。

## 2. 每阶段里程碑

### N0｜现状审计与基线冻结
**完成定义：**
- 所有 V1.0 模块完成状态标记；
- V1.3 PRD 的 MVP 验收项逐条验证；
- 核心链路有真实数据演示；
- 形成差距、复用、风险和技术债务清单；
- 用户确认下一阶段范围。

### N1｜HF 数据接入 MVP 固化
**完成定义：**
- 至少一个公开第一人称 Dataset Repo 成功导入；
- Dataset Card、License、Revision、Split 可追溯；
- 小样本下载或 Streaming 正常；
- Generic Video 或 LeRobot 至少一种真实结构完成解析，目标覆盖 LeRobot v2.1 / v3.0；
- 播放、时间轴和真实字段联动；
- 人工审核记录持久化；
- 质量报告由真实记录计算；
- Token、缓存和许可边界通过检查。

### N2｜Canonical Schema 与 Adapter
**完成定义：**
- Adapter 注册、发现和版本机制可用；
- 两种不同数据来源或格式映射到同一 Canonical Schema；
- 字段映射、缺失字段和转换错误可追溯；
- 原始字段不丢失；
- Adapter 具备自动化测试夹具。

### N3｜多模态 Pipeline 与 Episode
**完成定义：**
- 处理任务具备状态、日志、参数、输入输出和错误；
- 时间戳转换依据可追溯；
- Episode 切片规则可配置、可版本化；
- 多路媒体流同步偏差可检测；
- 处理可重试、幂等且不覆盖原始数据。

### N4｜标注与质量中心
**完成定义：**
- Label Schema 可版本化；
- 标注任务可提交、审核和返工；
- 自动质检规则可配置和复现；
- 问题可定位到样本/时间段/规则；
- 第三方标注工具优先集成；
- AI 结果与人工结果分开存储。

### N5｜数据资产与 Dataset 生命周期
**完成定义：**
- 资产可按项目、来源、设备、Episode、标签和质量检索；
- Dataset 可筛选、去重、划分和冻结；
- Dataset Version 具有 Manifest、Hash、Schema、规则和 Pipeline 版本；
- 数据血缘正向/反向追溯；
- 导出数据与 Manifest 一致。

### N6｜训练集成与模型评测
**完成定义：**
- Training Request 可登记并匹配数据集；
- 数据交付与版本冻结关联；
- 外部训练任务和模型版本引用可记录；
- 评测结果关联 Dataset Version 和 Model Version；
- 不重复建设完整训练集群。

### N7｜模型反馈闭环
**完成定义：**
- 失败案例可归档、分类和追溯；
- 数据缺口分析有规则和证据；
- 可生成候选数据需求；
- 人工确认后进入需求管理；
- 新数据版本与模型效果变化可比较。

### N8｜真实采集与设备集成
**完成定义：**
- 至少一种真实机器人/设备数据格式完成端到端验证；
- 设备能力与状态有真实来源；
- 采集任务、设备、数据、Episode、质检和资产关联；
- 无硬件条件的适配项标记 BLOCKED。

### N9｜规模化运营与企业治理
**完成定义：**
- 多项目隔离、权限和审计通过测试；
- 多基地、供应商、人员和设备资源可管理；
- 产能、质量、成本和交付指标有口径；
- 备份恢复和安全检查有演练证据。

## 4. 阶段推进门禁

一个阶段只有同时满足以下条件才可标记完成：
1. 范围和验收标准已冻结；
2. 功能在真实环境或可复现测试环境中运行；
3. 关键测试通过；
4. 数据安全、权限和质量检查通过；
5. 文档和 API / Schema 契约同步；
6. GitHub PR 已审查并合并（如需合并）；
7. 交付证据可复核；
8. 用户明确验收。

`Code Complete`、`Test Passed`、`QA Accepted`、`User Accepted`、`Released` 必须分别记录，不得混用。
