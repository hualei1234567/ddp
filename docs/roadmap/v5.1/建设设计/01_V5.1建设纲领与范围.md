# 01｜V5.1 建设纲领与范围

## 1. 版本定位
V5.1 是“真实数据生产闭环版本”，解决平台从数据管理工具走向具身训练数据生产系统的关键差距。V4.1 已完成的 Agent 协议、上传、QC Worker、Dataset Builder、Canonical Export、LeRobot 元数据 Loader 等能力继续复用。

## 2. 北极星验收目标
给定一份真实机器人数据样本：系统识别格式和版本；解析真实 SensorStream；逐帧生成 Observation；有真实动作源时生成 Action；保留时间戳、单位、坐标系、标定、采样率和源文件引用；完成多流同步和 Episode 分段；执行 DATA_CLEANING；完成标注、QC、审核；冻结 DatasetVersion；官方 Loader 读取真实逐帧 Parquet / 视频 / feature；样本能反向追溯到 RawAsset / CaptureSession / Device / Calibration / Pipeline；同一输入、同一版本、同一参数可复现相同产物。

## 3. 不新增顶层业务模块
沿用 Robot / Device / Sensor / Calibration / CaptureSession / EdgeAgent；Upload / RawAsset / MinIO / Ingestion / Adapter / ProcessingRun / Episode；AnnotationTask / Batch / Assignment / Submission / Workbench / AiSuggestion；QC / Review / Rework；Dataset / DatasetVersion / Manifest / Export / TrainingRequest / ModelOps；Identity / ProjectScope / ROLE_PERMISSIONS / Outbox / Worker / Ops。
允许在既有领域内部增加必要字段、服务、交互和 API，但必须先证明现有对象无法表达，并提交 ADR。禁止新建同义的任务中心、数据中心、质检中心、Agent 中台或第二套权限系统。

## 4. V5.1 范围
**P0：** FR-009~012 真实传感器物化与同步；FR-013 格式能力实证；FR-014 DATA_CLEANING；FR-015 步骤级幂等重试；FR-044 多角色浏览器 E2E；FR-019 标注冲突恢复；FR-040 Lineage E2E；FR-043 PG/MinIO/Spool 恢复；FR-045 Frozen Dataset 引用保护；FR-025 QC 证据区间可视化。  
**P1：** FR-020 分配前负载提示；Dataset 逐帧训练就绪；Staging / 硬件 Pilot（外部资源到位后）；运营指标闭环。  
**条件性 P2：** GPU 真实模型推理；外部训练平台连接器。

## 5. 明确不做
不重写已 VERIFIED 的 Agent、上传、MinIO、Outbox、QC、Dataset Builder、RBAC；不把 METADATA_ONLY 改名为训练就绪；不把合成数据或公开数据测试冒充硬件 Pilot；无动作源不臆造 Action；不覆盖 RawAsset；不默认引入 Kafka/Celery/Kubernetes/微服务；Agent 不执行任意远程 shell 或机器人运动控制。

## 6. 交付原则
每个功能必须有用户操作、系统行为、数据契约、状态变化、失败路径、权限规则、可观测指标和验收测试。只有文档、静态 UI 或 Mock 不算完成。
