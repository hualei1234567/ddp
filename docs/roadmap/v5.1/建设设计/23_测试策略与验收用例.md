# 23｜测试策略与验收用例

## 1. 测试层级
Unit：Parser、时间转换、单位、坐标变换、Cleaning Rule、幂等键。  
Contract：Canonical Schema、Adapter capability、OpenAPI、LeRobot feature mapping。  
Integration：PostgreSQL、MinIO、Outbox、Worker、对象引用。  
UI Interaction：冲突恢复、QC 证据跳转、负载预览。  
Browser E2E：多角色权限、Dataset 操作、全链路导航。  
Data Fixture：真实公开数据或现场样本。  
Hardware Pilot：真实机器人/传感器。  
Recovery：PG、MinIO、Spool 独立和联合恢复。

## 2. 数据物化测试
正常流、缺失流、Action 不存在、时间戳单位错误、时间回退/重复、dtype/shape 不匹配、单位未知、标定缺失、文件损坏、部分流成功部分失败、Parser 重跑、Worker 中断、上游参数变化。

## 3. 时间同步测试
共享时钟、固定 offset、线性 drift、非线性跳变、不同采样率、不重叠时间范围、不确定度超阈值、人工校准版本变更。

## 4. Cleaning 测试
NaN/Inf、传感器越界、重复时间戳、黑帧/冻结帧、关节速度超限、空 Episode、短 Episode、必需流缺失、RawAsset 不可变、清洗输出 Hash 和规则版本。

## 5. Dataset Loader 测试
metadata、Parquet frame、video decode、Observation feature、Action feature（有源时）、fps/timestamp、multi-episode、batch iteration、stats、manifest hash、corrupt file、incomplete episode。

## 6. 权限和数据保护测试
跨 Project URL、跨 Project API、未授权下载、Annotation 归属、Reviewer 状态机、Dataset 冻结、RawAsset 被引用时删除、归档/软删除权限、过期 Session。

## 7. 最终 E2E
真实或有许可公开样本 → Upload → RawAsset → Adapter → SensorStream → Observation/Action → Sync → Episode → Cleaning → Annotation → QC → Review → Dataset Freeze → LeRobot Export → Frame-level Loader → Lineage。
样本不是现场硬件时，必须标记 `PUBLIC_DATASET_INTEGRATION_TESTED`，不能标为真实硬件 Pilot。
