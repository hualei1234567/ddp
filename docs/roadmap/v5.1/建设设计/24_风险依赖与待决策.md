# 24｜风险、外部依赖与待决策

## 1. 已知风险继承
V4.1 风险登记册 64 项：P1 24 / P2 40。M0 必须逐项导入并与最新 risk-list 对账，不能假设已关闭。

## 2. 核心风险
| 风险 | 影响 | 缓解 |
|---|---|---|
| 无真实传感器样本 | Parser 只对合成数据有效 | 先样本盘点，选 Golden Path |
| 多格式范围过大 | Adapter 适配拖垮项目 | 单一 Golden Path 先闭环 |
| Canonical 过早变更 | 全链路兼容成本高 | 先映射验证，ADR 后升级 |
| 时间同步错误 | 训练样本语义错位 | 原始时间保留、同步证据化 |
| Action 被错误推断 | 训练监督信号污染 | 无源不生成 |
| 清洗过度 | 丢失有效困难样本 | FLAG 默认优先、隔离可恢复 |
| Loader 只读 metadata | 误报训练就绪 | 独立 Frame-level Gate |
| Frozen Dataset 资产被删 | 数据集不可复现 | 引用保护和删除预览 |
| 权限只测 API | UI/浏览器路径越权 | 多角色浏览器 E2E |
| 恢复无演练 | 故障后无法恢复 | PG/MinIO/Spool Runbook |

## 3. 外部依赖
真实机器人样本或有许可的公开机器人数据；硬件 Pilot 所需机器人、传感器、工作站、SDK/导出方式；Staging 所需主机、网络、Secrets、域名/证书；AI 所需 GPU、驱动、模型权重和许可；训练平台连接器所需正式 API、认证、回调/轮询协议。

## 4. 必须确认
1. V5.1 Golden Path 首选数据格式和样本来源；
2. 是否可用公开数据集作为第一阶段真实 payload 集成测试；
3. 第一台 Pilot 机器人/传感器组合；
4. 数据清洗业务阈值审批人；
5. PG/MinIO/Spool 目标 RPO/RTO；
6. Staging 资源负责人和预算；
7. AI GPU 与外部训练平台是否纳入本版本交付承诺。

## 5. 默认建议（待确认）
先选“能拿到真实样本、字段有文档、业务频率高”的格式作为 Golden Path；先完成公开/真实导出文件 Parser + Frame-level Loader；硬件 Pilot 与 Staging 并行准备；AI/GPU 和训练平台不阻塞核心数据链。
