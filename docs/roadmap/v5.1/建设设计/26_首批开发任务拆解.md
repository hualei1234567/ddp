# 26｜V5.1 首批开发任务拆解

## Sprint 0：基线和样本（不改业务代码）
**T0-01 最新代码基线复核：** HEAD、Migration、OpenAPI、测试、CI、风险清单；验收：可复现审计快照。  
**T0-02 现有代码复用映射：** Parser、Canonical、ProcessingRun、Artifact、Lineage、Dataset、Retention 实际路径；验收：每项 FR 有复用路径和差距。  
**T0-03 样本盘点：** fixture、公开数据样本、真实设备导出；记录许可、格式、流、Action、Calibration、时间戳；验收：选定 Golden Path 或明确 BLOCKED 原因。  
**T0-04 LeRobot 当前能力复核：** metadata / frame / video / observation / action 实际读取能力；验收：独立复现报告。

## Sprint 1：无硬件治理缺口
**T1-01 RBAC Browser E2E：** 至少两个 Project、多角色、URL/API/下载越权拒绝；验收：CI 可重复。  
**T1-02 Frozen Dataset 引用保护：** 事务级阻止删除冻结 Dataset 引用的 RawAsset/Artifact；删除预览列出引用链；验收：并发删除/冻结竞态测试。  
**T1-03 标注冲突恢复：** 草稿保护、差异对比、复制本地草稿、人工合并；验收：双用户并发编辑 E2E。  
**T1-04 QC 证据定位：** 点击规则证据跳转 Episode 时间轴；验收：时间、流、字段和值准确。  
**T1-05 恢复演练：** PG、MinIO、Spool Runbook 和隔离环境演练；验收：Hash、引用和恢复耗时报告。

## Sprint 2：Golden Path 数据物化
**T2-01 Adapter 能力分级：** 选定格式建立 detect/inspect/payload/stream/episode/round-trip 测试；验收：能力矩阵有真实 fixture 证据。  
**T2-02 SensorStream Producer：** 从真实 payload 解析并持久化；验收：非空流、样本数和 Hash 对照。  
**T2-03 Observation Producer：** 逐帧/逐采样输出真实 payload；验收：dtype/shape/unit/time/source index 正确。  
**T2-04 Action Producer：** 仅当真实动作源存在时开发；验收：与源通道抽样对照；否则输出 ACTION_SOURCE_ABSENT。  
**T2-05 Time Sync / Calibration：** 记录 raw/normalized time、offset/drift、calibration snapshot；验收：多流样本误差报告。  
**T2-06 Episode Segmentation：** 使用可解释分段规则；验收：边界正确、重跑幂等。  
**T2-07 DATA_CLEANING：** 先上线 FLAG 规则，再逐步启用 TRANSFORM/QUARANTINE；验收：RawAsset 不变，清洗证据完整。  
**T2-08 Step Retry：** 成功产物去重、失败步骤重试；验收：崩溃/重跑无分叉。

## Sprint 3：训练就绪与全链路
**T3-01 LeRobot Frame-level Loader：** 真实 Parquet、Video、Observation、Action（有源时）；验收：官方 Loader 逐帧读取。  
**T3-02 Lineage E2E：** DatasetItem 到 RawAsset / Session 正反向追溯；验收：真实数据 E2E。  
**T3-03 Dataset Gate：** 检查 Stream、Observation、时间、QC、Lineage 和 Loader 适用条件；验收：不合格数据阻断冻结或显式豁免。

## Sprint 4：外部资源门禁
T4-01 Staging：资源到位后部署。  
T4-02 Hardware Pilot：设备和样本到位后执行。  
T4-03 AI GPU：权重和 GPU 到位后接真实推理。  
T4-04 Training API：外部 API 契约到位后连接。

## 任务准入要求
每个任务开工前提交：关联 V51 ID、现有代码路径、真实差距、方案、API/DB 影响、权限、测试、回滚、完成证据。没有这些信息不得直接开工。
