# 10｜数据质量证据与 QC 增强

## 1. V4.1 基础复用
QC 自动触发、Worker、幂等、CAS、死信、批量重跑 UI、差异报告和失败项重试已 VERIFIED。V5.1 不重做批量 QC，而是补齐证据解释、时间定位和数据质量规则联动。

## 2. QC 结果数据
每条结果可显示 rule_id/version、severity、subject、field_path、expected/actual、time range、stream_id、evidence artifact、sample index、retry status、remediation hint。

## 3. 证据定位
点击 QC issue → 打开对应 Episode → 播放器跳转证据时间 → 时间轴高亮区间 → 对应 Stream 高亮 → 展示原始值/规范化值/规则阈值 → 查看 Raw Source / Processing Artifact → 需要返工时创建 Rework 并自动附带 issue context。

## 4. 多模态证据
媒体：帧/时间范围/解码错误。数值流：样本索引、时间、值、单位、阈值。动作流：Action 类型、时间、来源通道、异常原因。同步：offset/drift/error distribution。标注：标签键、父子关系、区间和 Schema 版本。

## 5. 人工审核边界
QC 自动规则提供证据和建议，不自动代替 Reviewer。Reviewer 的 Accept/Rework/Arbitration 继续使用现有状态机和权限。

## 6. 验收
至少覆盖媒体时间区间、数值流越界、时间同步超差三类证据；点击证据能定位正确时间和流；规则版本明确；批量重跑不把入队回执渲染成最终结论。
