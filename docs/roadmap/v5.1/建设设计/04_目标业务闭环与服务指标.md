# 04｜目标业务闭环与服务指标

## 1. 目标主链
真实采集文件 / 合规公开机器人数据 → Agent / Upload → RawAsset → Adapter Format Qualification → SensorStream / Observation / Action → Time Sync + Calibration → Episode Segmentation → Data Cleaning → Annotation / AI Suggestion（可选）→ QC / Review → Dataset Gate / Split → LeRobot Export → Official Loader Frame-level Read → DatasetItem Lineage → Training Handoff（外部接口具备时）。

## 2. 角色旅程
- 数据负责人：看采集数据可用性、解析成功率、异常分布、标注积压、QC、Dataset 可训练状态和风险。
- 采集人员：领取任务、Preflight、采集/导入、上传、查看文件完整性和 Session 状态。
- 标注人员：接任务、加载媒体与流、标注、自动保存；冲突时恢复草稿。
- 质检人员：看规则、证据区间、媒体上下文；接受、返工或仲裁。
- 算法人员：看逐帧可读范围、Observation/Action features、fps、任务定义、缺失率和 Loader 证据。
- 管理员：管理权限、保留策略、Agent、备份恢复和环境。

## 3. 数据可用性分级
`RAW_INGESTED` → `METADATA_PARSED` → `STREAMS_EXTRACTED` → `EPISODE_READY` → `ANNOTATION_READY` → `QC_ACCEPTED` → `DATASET_FROZEN` → `LOADER_METADATA_VERIFIED` → `LOADER_FRAME_VERIFIED` → `TRAINING_HANDOFF_VERIFIED`。
这些是数据成熟度标签，不替换现有领域状态机。

## 4. 运营指标
| 指标 | 口径 |
|---|---|
| 原始文件校验通过率 | checksum pass / 完成上传文件 |
| Adapter 能力通过率 | 通过 fixture / 执行 fixture，按格式分开 |
| Stream 提取成功率 | 有效流 / 声明应有流 |
| Observation 有效率 | 有效逐帧记录 / 期望记录 |
| Action 覆盖率 | 有真实动作源的 Episode 中可解析比例 |
| 时间同步合格率 | 满足项目阈值的 sync group / 可评估 group |
| 清洗隔离率 | 被隔离样本 / 处理样本 |
| QC 一次通过率 | 首次 QC PASS / 首次提交 |
| 标注冲突恢复率 | 成功恢复草稿 / 冲突事件 |
| Loader Frame Verified 比例 | 逐帧加载通过 Episode / 导出 Episode |
| Lineage 完整率 | 可追溯 DatasetItem / DatasetItem 总数 |
| 恢复演练通过率 | 通过检查项 / 总检查项 |

不得把处理数量、上传量当作数据价值指标；必须同时看有效率和训练可读性。
