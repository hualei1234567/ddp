# 05｜真实数据样本准入与格式适配

## 1. 为什么先做样本准入
V4.1 审计明确 S3 阻塞于真实传感器样本。没有样本时按猜测写 Parser，最终可能只支持自造 JSON。V5.1 第一项不是写 Parser，而是建立样本登记和样本质量门禁。

## 2. 样本来源分层
A. 真实硬件现场导出：最高优先级，可用于真实设备 Pilot。  
B. 有许可的公开机器人数据集：用于 Adapter、解析、同步和 Loader 的真实数据测试，但不能冒充本项目硬件 Pilot。  
C. 合成 fixture：用于边界、异常、幂等和单元测试，不可作为真实格式兼容的唯一证据。

## 3. 样本登记字段
sample_id、project_id、source_type、source_dataset、license、robot/vendor/model、firmware/SDK version、format/container version、capture software version、sensor inventory、calibration files、clock metadata、action source、file tree、file sizes、SHA256、privacy classification、consent/permission、known issue、owner、approved use。

## 4. 样本准入检查
文件 Hash 可复算；文件树和大小完整；格式版本可识别；时间戳单位和来源可说明；流的 dtype/shape/unit 可解释；传感器与设备映射明确；坐标系和标定可用或明确缺失；Action 是否存在及来源明确；许可和脱敏要求通过。缺失信息不猜测，写 `UNKNOWN` / `NOT_PROVIDED` 并影响能力等级。

## 5. Adapter 能力分级
| 等级 | 含义 | 可宣称 |
|---|---|---|
| DETECT | 识别文件/容器 | 可识别格式 |
| INSPECT | 读取元数据 | 可读取元数据 |
| PAYLOAD_PARSE | 读取真实 payload | 可解析数据内容 |
| STREAM_EXTRACT | 输出 SensorStream / Observation / Action | 可提取数据流 |
| EPISODE_BUILD | 构建带时间域 Episode | 可生成 Episode |
| ROUND_TRIP | 输出可被目标 Loader 读取 | 可通过往返验证 |

每个格式独立记录等级，不允许“Adapter 注册成功”就显示“完整支持”。

## 6. 首批格式策略
优先选择仓库已有 Adapter 中、用户能提供真实样本且业务价值最高的一种作为 P0 Golden Path。HDF5、ROS Bag、MCAP、LeRobot、DROID、Parquet、Media 分别维护能力矩阵；不要求一轮内所有格式达到最高等级。

## 7. Golden Fixture 包
每个格式建立 manifest、原始样本或经许可最小样本、expected metadata、expected streams、expected observation/action shape、timestamps、episode boundaries、warnings/errors、SHA256、parser version、复现命令和测试结果。Expected output 变更必须评审并说明来源。
