# 19｜运行监控与数据运营指标

## 1. 复用现有 Ops
FR-042 `GET /ops/dispatch-queue` 已 VERIFIED。V5.1 扩展已有 Ops 页面和只读 API，不新建运维中心。

## 2. 运行维度
Agent：在线率、版本、心跳延迟、磁盘、Spool bytes、上传队列、Lease。  
Upload：吞吐、失败、续传、Hash 错误、耗时。  
Processing：队列长度、最老任务、步骤失败、重试次数、解析耗时。  
Data：各格式 Adapter 能力等级、Stream 提取率、Observation 缺失率、Action 来源覆盖、同步误差、清洗隔离率。  
Annotation：任务积压、冲突数、草稿恢复、逾期、人员负载。  
QC：PASS/WARN/FAIL、规则分布、重跑耗时、返工率。  
Dataset：Gate 排除原因、Split 泄漏检查、Loader metadata/frame 状态、Lineage 完整率。  
Infra：DB、MinIO、Worker、Staging、备份状态。

## 3. 指标设计
每个指标有 definition、query、window、dimensions、owner、alert threshold、known limitation。禁止用未定义分母的百分比。

## 4. 告警等级
P0：数据可能丢失、跨项目越权、Frozen Dataset 被破坏。  
P1：Worker 长时间积压、关键解析持续失败、对象缺失、备份失败。  
P2：负载偏高、质量指标趋势异常、单格式兼容退化。  
告警包含影响范围、关联 ID、排查入口和建议动作。

## 5. 数据运营看板
以数据可用性漏斗展示 RAW_INGESTED → STREAMS_EXTRACTED → EPISODE_READY → QC_ACCEPTED → DATASET_FROZEN → LOADER_FRAME_VERIFIED。每一步显示数量、转化率、排除原因和平均耗时。
