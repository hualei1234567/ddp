# 15｜测试策略与真实链路验收用例

## 1. 质量基线
2026-11-23：`scripts/check.sh` 9 步通过；后端 2871 用例通过；前端 1072 passed / 19 skipped；build 成功；CI 五项全绿。V4.1 不允许降低门禁换进度。

## 2. 测试层
Unit：状态机、Schema、Adapter、时间同步、QC Rule。  
API：权限、幂等、If-Match、错误码。  
Integration：PostgreSQL、MinIO、Outbox、Worker。  
Frontend Interaction：真实 DOM、异步保存、时间轴、批量操作。  
E2E：浏览器 + API + DB + MinIO + Worker。  
Pilot：真实设备导出文件。  
Recovery：断网、Agent 重启、Worker 崩溃。  
Security：ProjectScope、Agent Token、文件访问。  
Performance：大文件、长视频、批量 QC、队列。

## 3. Agent 必测
配对码过期、Agent 撤销、心跳丢失、Lease 冲突、Agent 重启、磁盘不足、Adapter 不支持、断网续传、Manifest 篡改、Hash 不一致。

## 4. 数据处理必测
重复 ACK、ETag 篡改、重复 Complete、URL 过期、部分文件缺失、MinIO 暂时失败、Outbox 重复、Worker 中断、Episode 已成功后重试、容器格式 SKIPPED。

## 5. 标注必测
L2 无 L1、L3 无 L2、子区间越界、OUTCOME_SPAN 原因缺失、自动保存失败、If-Match 冲突、提交时保存仍 pending、AI 采纳/修改/拒绝、多角色权限；确认帧级框选画布没有被擅自加入。

## 6. QC 必测
Submission 自动触发、Worker 重复执行、批量重跑重复点击、规则版本变化、差异报告、失败项重试、Rework 新版本、冻结 Dataset 不重写。

## 7. Dataset / Training 必测
Gate 阻止未审核样本；Split 按 Session 分组；Manifest Hash；官方 Loader 读取 Parquet 和视频；feature shape/fps/task metadata；Loader 失败时保持 UNVERIFIED；Mock/Real 区分；Callback 验签和重复回调幂等。

## 8. E2E A：File-based Pilot
真实机器人导出文件 → CollectionTask → CaptureSession → Agent → Manifest → MinIO → RawAsset → Adapter → Canonical → Episode → Assignment → Workbench → Submission → QC → Review → Dataset Freeze → Export → Loader。
若不是现场硬件采集，标记 `HARDWARE_CAPTURE_NOT_TESTED`。

## 9. E2E B：真实硬件 Pilot
真实机器人/传感器 → Edge Agent → CaptureSession → 多流采集 → 上传 → SensorStream/Observation/Action → Episode → 标注 → QC → Dataset → Loader。只有硬件真实运行、数据真实生成、证据齐全才通过。

## 10. 证据包
Git commit、环境版本、Agent version、Robot/Device/Sensor 型号、Manifest、文件 Hash、Upload logs、ProcessingRun、Episode IDs、Submission IDs、QC/Review、Dataset Manifest、Export Hash、Loader 版本/输出、测试命令/退出码、录屏或截图。

Code Complete、Test Passed、E2E Passed、User Accepted、Released 分别记录。
