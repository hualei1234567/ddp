## 4. 推荐默认方案（待 D2 确认）
Edge Agent 部署在采集工作站/边缘计算机；通过出站 HTTPS 调用现有 API；优先 Filesystem Export Adapter；本地 Spool + Manifest 保障断网恢复；不部署到机器人运动控制器；不提供任意远程命令。该推荐不是已批准决策。

## 5. 风险规则
P0 阻断安全、数据正确性或主链；P1 影响真实可用性和交付可靠性；P2 体验/效率。每项风险有 Owner、期限、缓解动作、证据。BLOCKED 必须有解除条件，不能仅靠修改文档关闭。
