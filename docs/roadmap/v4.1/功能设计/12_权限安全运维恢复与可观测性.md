# 12｜权限、安全、运维、恢复和可观测性

## 1. 权限
沿用 Identity、ROLE_PERMISSIONS、ProjectScope，不新建平行 RBAC。Collector 只执行分配任务；Agent 只访问授权工作站/设备/任务；Annotator 只编辑有效 Assignment；Reviewer 只审核授权 Project；Dataset 用户只读有权限版本；Training Adapter 使用服务身份。后端强制检查权限。

## 2. Agent 安全
独立身份、一次性配对、Token 轮换/撤销、TLS、最小权限、禁止远程任意 shell、禁止机器人运动控制、日志脱敏、凭据不进入 Manifest。

## 3. 文件安全
预签名 URL 受部署上限约束（审计记录 TTL 上限 3600s）；服务端生成 object key；文件名不作为授权依据；路径穿越防护；MIME + magic bytes + size + checksum；未验证资产隔离；下载审计不记录签名 URL/凭据。

## 4. 关联键
request_id / trace_id / correlation_id / project_id / collection_task_id / capture_session_id / agent_id / upload_session_id / raw_asset_id / processing_run_id / episode_id / annotation_task_id / submission_id / qc_run_id / dataset_version_id / export_job_id / training_request_id。

## 5. 监控
Agent 在线率/心跳/版本；Spool 积压；Upload 吞吐/续传/Hash 失败；Ingestion/Processing 队列延迟；Adapter 解析成功率；Episode 异常；Annotation backlog/保存失败/冲突；QC 失败率/重跑耗时；Review 周期/返工率；Dataset Export 失败；Loader 验证；Training Real/Mock 分布。

## 6. Staging
当前审计为 BLOCKED。需核验主机、网络、Secrets、PostgreSQL、MinIO、API、Outbox Worker、前端、Migration、Health checks、E2E 数据、日志监控。全部通过后才标记 READY。

## 7. 恢复
Agent：本地 Spool + 重启恢复；Upload：分片恢复；Worker：Outbox 重试和死信；Processing：步骤级重试；Annotation：服务端草稿和乐观锁；QC：Run 可追溯；Export：Job 可恢复；Training：请求幂等、回调验签、轮询补偿。

## 8. 备份
PostgreSQL 和 MinIO 分开备份；校验对象引用和实际对象；恢复演练；Frozen Dataset 的 Manifest 和依赖文件可校验；被 Dataset 引用的 RawAsset 不得静默删除。
