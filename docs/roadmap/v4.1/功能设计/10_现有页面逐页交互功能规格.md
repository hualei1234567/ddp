# 10｜现有页面逐页交互功能规格（不新增顶层模块）

## 1. 工作台首页
目标是呈现角色下一步待办，而非堆静态 KPI。
- 数据负责人：待发布采集任务、上传异常、解析失败、待分配标注、待审核、可冻结 Dataset；
- 采集人员：我的采集任务、Agent 状态、当前 Session、上传积压；
- 标注人员：待标注、进行中、返工、即将超期、保存失败；
- 审核人员：待审核、QC 失败、批量重跑、仲裁；
- 算法人员：最新 DatasetVersion、Loader 验证、训练交付状态。
卡片点击进入已有列表并携带筛选条件。

## 2. 采集任务页面
创建/编辑任务；选择项目、场景、动作、设备、传感器、标定、SOP、目标数量；指定采集人和工作站；发布/暂停/取消；查看 Session；查看完成量、失败量、补采量。发布后参数形成版本快照。只有状态机允许的动作才展示。

## 3. 设备页面
沿用现有设备页面，增加 Agent 状态：配对/撤销、在线状态、版本、心跳、当前 Session、磁盘、Spool 积压、Adapter 健康、最近错误和诊断信息。

## 4. 上传中心
显示文件级进度、已完成分片、重试状态、Hash、服务端校验、RawAsset ID、Ingestion 状态、隔离原因和重试失败项。不得暴露长期有效签名 URL。

## 5. Episode Explorer
项目/任务/Session/设备/格式/状态筛选；多视角媒体；Stream 元数据；时间同步状态；Canonical 预览；Raw 引用；ProcessingRun 历史；失败步骤/重试；批量选择创建 Annotation Batch。

## 6. 标注任务 / 我的任务
显示 Task、Episode、Batch、Assignee、Schema Version、状态、优先级、Due Date、估算时长、返工次数、QC 状态；按权限支持批量分配、转派和回收。

## 7. 标注工作台
沿用现有 Workbench、MediaPreview、EpisodeMediaPanel、AnnotationTimeline、AiSuggestionPanel。保留播放器、倍速、帧步进、快捷键、时间轴编辑、L1/L2/L3 多轨、OUTCOME_SPAN、AI 建议。补服务端语义校验反馈、提交前校验摘要、保存冲突恢复。禁止增加帧级框选画布。

## 8. 质量页面
QC 运行列表和详情、规则结果、审核队列、Accept/Rework/Arbitration、批量重跑入口、重跑预览、差异报告、失败项重试和质量统计。

## 9. Dataset 页面
沿用 Builder：候选样本、Gate 排除原因、标签/场景/设备覆盖、split、冻结确认、Manifest、ExportJob、LeRobot Loader 验证状态、下载和交付记录。

## 10. Training / ModelOps 页面
明确 MOCK / DRY_RUN / REAL；显示外部平台连接状态；真实提交后展示 external_run_id；显示 callback/polling 状态、训练日志、模型产物、失败原因和重试；模型与 DatasetVersion 关联。

## 11. 统一交互规范
所有列表有 Loading/Empty/Error/Partial Success/Forbidden/Stale Data/Retry/Pagination/Filter Persistence。批量动作先预览影响；不可逆动作确认；状态变更等待服务端成功后更新 UI。
