# 06｜标注工作台与三级语义功能设计

## 1. 已有能力，不重做
Task/Batch/Assignment/Submission；Workbench 草稿/乐观锁/提交；视频播放/倍速/帧步进/快捷键/时钟；时间轴拖拽、片段边界编辑和删除；OBJECT_TRACK 行编辑器；审核媒体证据视图；L1/L2/L3、OUTCOME_SPAN、多轨道和事件图建议映射均已 VERIFIED。

**FRAME / OBJECT_TRACK 帧级框选画布明确 NOT_IN_SCOPE。**

## 2. 标注员操作
我的任务 → 筛选 → 打开 Assignment → 检查 Lease → 加载 Episode/媒体/Schema/历史标注 → 播放审看 → 创建/编辑 L1/L2/L3 片段 → 编辑 OUTCOME_SPAN → 审核 AI 建议 → 自动保存 → 本地预校验 → 提交 → 服务端校验 → 生成不可变 Submission Version。

## 3. 三级语义
L1=SEMANTIC_TASK；L2=SEMANTIC_SUBTASK；L3=EVENT；OUTCOME_SPAN 表示结果区间，沿用现有枚举和 preset，不随意改名。

## 4. 服务端提交约束
- 每个 L2 必须归属合法 L1；
- 每个 L3 必须归属合法 L2；
- 子片段范围必须位于父级允许范围；
- 不允许悬空 parent_id 或跨 Episode 关联；
- 删除父级时不能静默遗留子级，默认提示先处理子级；
- OUTCOME_SPAN start < end，且位于 Episode 时长内；
- outcome 枚举合法；
- failure 时满足 Schema 对 failure reason 的要求；
- 重叠规则由 Schema 决定；
- 服务端提交时再次验证，不只依赖前端。

草稿允许暂时不完整，但应显示 warnings；提交时 blocking rules 必须通过。

## 5. 保存和冲突
沿用 If-Match/row_version。显示 Saving/Saved/Failed/Conflict。提交前等待所有保存请求完成。冲突时不自动覆盖，展示本地与服务端版本，提供刷新、复制本地草稿、人工合并。离开页面前提示未保存内容。

## 6. AI 建议
建议轨道与人工标签区分，显示模型、版本、置信度、生成时间。支持单条采纳、修改后采纳、拒绝。采纳后写入人工 Annotation Result，保留 AI 原始输出。AI 输出不能直接变成 Accepted/Reviewed。

## 7. 验收
L2 无 L1、L3 无 L2、越界子片段、非法 OUTCOME_SPAN 均提交失败并返回准确字段路径；前后端规则一致；冲突不覆盖；AI 建议与人工结果分离；不开发帧级框选画布。
