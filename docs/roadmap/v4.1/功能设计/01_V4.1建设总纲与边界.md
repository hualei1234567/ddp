# 01｜V4.1 建设总纲与边界

## 1. 定位
V4.1 是 DDP 现有功能的生产化完成版本：不增加业务模块数量，把采集、数据处理、标注、质检、数据集和训练交付做到可执行、可恢复、可追溯、可验收。

## 2. 目标
- **真实采集：** 在采集工作站运行 Edge Agent，完成身份、任务绑定、Preflight、采集文件发现、Manifest、本地缓存、上传恢复和 Session 回写；Agent 不接管机器人运动控制。
- **真实数据：** 不止生成 Episode 元信息，还要把真实 SensorStream、Observation、Action、时间戳、单位、坐标系和标定快照物化到 Canonical。
- **标注可靠：** 保留现有 Workbench、视频、时间轴、三级语义、结果帧和 AI 建议；补齐 L2⊆L1、L3⊆L2 服务端提交约束和异常恢复。
- **AI 真运行：** 把已有 AI Suggestion、事件图 Adapter、AI Suggestion Panel 接入真实模型环境；模型结果是建议，不直接成为训练真值。
- **质检完整：** 保留异步 QC 后端，补齐批量重跑入口、预览、差异报告、失败项重试。
- **训练数据可加载：** 保留 Dataset Builder、Manifest、Canonical/LeRobot Writer，完成官方 LeRobot Loader 隔离环境实测。
- **训练交付真实：** MOCK/DRY_RUN 与 REAL 明确区分；具备外部平台接口后才允许显示真实同步。
- **环境可验收：** Staging 可部署、Worker 可运行、MinIO 可访问、迁移和关键 E2E 通过。

## 3. 不新增模块
只在现有页面、领域和 API 中增量改造：
Robot/Device/Sensor/Calibration/CaptureSession；Upload/RawAsset/MinIO/Ingestion；Adapter/Canonical/ProcessingRun/Episode；AnnotationTask/Batch/Assignment/Submission/Workbench；AiSuggestion；QC/Review/Rework；Dataset/Version/Manifest/Export；TrainingRequest/ModelOps/Inference；Identity/ProjectScope/ROLE_PERMISSIONS；DB Outbox + Worker。

若现有对象无法表达必要行为，先写 ADR 说明现状、缺口、最小变更、Migration/API 影响，经审查后才允许改模型。

## 4. 不在范围内
新增业务导航、重复状态机、机器人运动控制、FRAME/OBJECT_TRACK 帧级框选画布、未经授权的私有协议逆向、所有厂商 SDK 一次性接入、训练集群调度、多租户商业结算、无接口条件下的虚构训练集成。

## 5. 工程原则
Reuse First；Evidence First；Raw Immutable；Schema/Model/Pipeline/Rule/Dataset 全版本化；状态由 Domain 控制；异步任务幂等；失败是产品状态；无 Mock 验收；所有结果可追溯。
