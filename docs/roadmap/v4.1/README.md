# DDP V4.1 功能级全面建设蓝图包

**版本定位：** 不增加业务模块，完成现有功能的生产化、可操作化、可恢复化和可验收化。  
**审计依据：** DDP V3.1 全面审计报告（2026-11-23）；基线 `origin/main @ 3d45344`。

## 本版不做
- 不新增顶层业务模块或重复菜单；
- 不重写已 VERIFIED 的上传、MinIO、Workbench、QC 后端、Dataset Builder；
- 不新建第二套状态机、权限体系或任务体系；
- 不引入 Kafka / Celery / Kubernetes / 微服务；
- 不做用户已明确决定不做的 FRAME / OBJECT_TRACK 帧级框选画布；
- 不宣称 LeRobot 已通过真实 Loader、训练平台已真实同步、AI 已有真实模型输出、Agent 已完成硬件采集或 staging 已可用。

## 组织方式
本包按用户工作流程和具体功能行为组织。每项设计说明：入口、前置条件、输入、操作、系统行为、数据变化、状态、异常、权限、验收和复用策略。不是新模块清单。

## 使用方式
把本包放入仓库 `docs/roadmap/v4.1/`（遵循现有目录规范），同时提供最新审计档案和 V31-010 ADR。第一轮先只读复核当前 HEAD、FR 状态和 D2 选项，输出基线报告后暂停。之后按 FR 编号逐项实施。

## 事实边界
2026-11-23 是最新可用审计快照，不保证当前 HEAD 未变化。开发前必须重新核对仓库、Migration、OpenAPI、测试和真实运行证据。没有 E1/E2/E3 证据不得标记 VERIFIED。
