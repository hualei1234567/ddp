### 6.2 平台显示问题修复

**现象**：底部「Agent 资源池」长期显示 `0 / 7`，花名册全部 offline。

**根因**：

1. 执行器启动/结束时只写调度项与执行记录，不回写 `project_agents.status`；
   资源池只统计 `idle/available`。
2. 平台新建 Agent 默认 `offline`，从未被置为可用。
3. 仓库没有 `ai-team/status` 时，花名册仍走会话扫描，扫不到就显示 offline。

**修复**：

- 执行器开始时写 `working`，结束写 `idle`，并更新 `last_heartbeat_at/last_seen_at`
  （`app/agent_platform/executor.py`）。
- 新项目 Agent 默认 `idle`（`service.py` 两处 INSERT）。
- 无 `ai-team/status` 目录时，花名册改用平台库（`agents_dashboard.py`）。
- 回填现有 13 个 offline Agent 为 idle；现平台资源池 **14 / 14**。
- DDP 补齐 `ai-team/status/*.json` 后，花名册 7 角色均显示 idle。

**验证**：
