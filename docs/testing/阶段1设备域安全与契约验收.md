- 结果：降级成功；设备域表全部删除；身份域 `users/projects/project_members` 保留。
- **风险提示**：0003 降级直接删除设备域表，带数据降级会丢失设备/传感器/标定数据；生产回滚必须先备份并人工批准，不能由 Agent 自动执行。
- 结论：**PASS（行为可执行）/ WARN（数据丢失语义）**。
