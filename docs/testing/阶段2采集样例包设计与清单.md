## 1. 目标与非目标

### 1.1 目标

1. 为 `S2-T01`–`S2-T30` 与补充专项用例提供可复用数据；
2. 覆盖多相机、机器人状态、语言指令、标定、Manifest、损坏/非法/超大、断点/重复、时间同步、Episode 边界、跨项目、弱网参数；
3. 让任何第三方在同一 Python 小版本下重复生成相同字节，并独立核对 SHA256；
4. 明确标注 Mock/合成范围，防止样例冒充真实业务验收。

### 1.2 非目标

- 不生成真实可播放的 H.264 视频、真实 MCAP/ROSBAG2/HDF5/Parquet 数据；
- 不生成真实 ZIP 炸弹、恶意软件或可执行攻击载荷；
- 不提供真实客户数据、真实设备序列号、真实标定参数或生产凭据；
- 不替代真实采集验收（AC-E2E-02）；
- 不把样例包本身作为阶段 2 测试通过证据。

## 2. 数据来源与标注

| 标注 | 含义 | 本包使用 |
|---|---|---|
| `YES` | 合成数据，可用于功能/契约/失败路径测试 | 相机、状态、指令、标定、Manifest、跨项目元数据 |
| `SYNTHETIC_NEGATIVE` | 合成负向/恶意样本，仅隔离环境使用 | 空文件、截断、文本伪装、未知格式、非法 JSON、畸形 CSV、ZIP、恶意文件名 |
| `SYNTHETIC_SPEC` | 仅用例参数模板，不是业务数据 | Episode 边界、时间同步、上传场景、跨项目用例 |
| `MOCK_SPEC` | 网络注入参数模板，必须记录工具/参数/时长 | 弱网/断网 profile |
| `REAL` | 真实设备、真实人员、真实场景、有效标定 | 未提供；AC-E2E-02 `BLOCKED` |

**规则：**

1. 所有样例在 manifest 中有 `data_source`、`mock_scope`、`purpose`、`expected`；
2. `SYNTHETIC_NEGATIVE` 不得进入真实数据目录、生产桶或常规上传链路；
3. `MOCK_SPEC` 只用于网络注入，不得作为真实请求/响应证据；
4. 合成数据不得进入真实看板分母；
5. 真实数据引入时必须另建目录并记录来源、脱敏说明、SHA256、批准人，不得覆盖本包。

## 5. 可复现规则

生成器只使用 Python 标准库，不访问网络/数据库/对象存储。可复现依赖以下固定项：

| 项 | 固定规则 |
|---|---|
| 时间基准 | `BASE_NS = 1730000000000000000`（2024-10-27T00:00:00Z） |
| 生成时间字段 | `generated_at_utc = 2026-11-08T00:00:00Z`（固定，不使用当前时间） |
| 随机性 | 无随机数；所有值由索引/常量计算 |
| JSON | `sort_keys=True`、`indent=2`、`ensure_ascii=False`、UTF-8、LF |
| CSV | UTF-8、LF、固定列顺序、固定 6 位小数 |
| ZIP | `ZIP_STORED`、固定 `date_time=(2026,1,1,0,0,0)`、固定条目顺序 |
| 文件遍历 | 按路径排序 |
| Manifest | 排除自身、`SHA256SUMS`、`large/**` |
| 平台注意 | 不同 Python 小版本/不同 zlib 实现可能影响压缩字节；本包 ZIP 使用 `ZIP_STORED` 规避压缩差异 |

**注意：** 如果新增/修改样例，必须同步重新生成 manifest 与 `SHA256SUMS`；不得手工编辑 manifest 中的 Hash。

## 8. 使用限制与安全要求

1. **不可冒充真实数据**：本包全部为 `[SYNTHETIC]`/`[SYNTHETIC_NEGATIVE]`/`[MOCK_SPEC]`；报告中必须标注；
2. **不可冒充真实解析**：MP4/MCAP/HDF5/PARQUET 只有签名/容器头，不能验证真实解码、采样、帧内容；
3. **负向样本隔离**：只在隔离目录/隔离环境使用；不得上传到生产桶或真实项目；
4. **不生成真实炸弹/恶意软件**：ZIP 仅路径穿越与嵌套；如需压缩炸弹/恶意载荷，必须在隔离环境经安全审批生成；
5. **不写入真实凭据**：样例中 UUID、checksum、标定值为合成常量，不对应真实设备；
6. **不作为验收结论**：样例包通过只证明测试数据可复现，不证明阶段 2 功能通过。
