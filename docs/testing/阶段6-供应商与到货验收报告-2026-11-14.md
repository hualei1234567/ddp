## 3. 本轮发现并修复的缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| `inbound_segments.duration_ns` 使用 `Integer` | 纳秒级时长（19 分钟 ≈ 1.14e12）超出 int32，真实 PG 插入报 `NumericValueOutOfRange` | 改为 `BigInteger`（与 `episodes.duration_ns` 一致），契约同步按 int64 描述 |
| SQLite `DROP TRIGGER ... ON table` 语法 | 迁移测试与 `create_all` 清理失败 | 按方言分支生成 DROP 语句 |
| 配置测试依赖开发机 `.env` | `test_env_defaults_to_production` 在本地有 `.env` 时失败 | 测试显式 `_env_file=None`，与开发者环境解耦 |
| 注释/授权测试写死 2026-11-09 | 到期校验按真实时钟判断，日期过去后误判过期 | 基线改为 `datetime.now(UTC)`，断言不变 |
| 供应商级账本无批次 | 账本 `batch_id NOT NULL` 导致登记失败 | 允许 `null`（供应商级事件），契约同步 |

> 后三项属于既有测试的时间脆弱性，本次一并修正；**未放宽任何断言**。
