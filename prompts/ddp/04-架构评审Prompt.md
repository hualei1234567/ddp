# DDP 架构评审 Prompt

请针对指定模块或变更做架构评审，不要默认建议重写。

评审对象：
- 模块 / PR / 方案：
- 业务目标：
- 当前实现位置：

从以下角度评估：
1. 是否符合现有系统架构和代码风格；
2. 是否重复已有功能；
3. 是否可以复用官方 SDK 或成熟开源项目；
4. 模块职责和依赖是否清晰；
5. API、Schema 和数据库兼容性；
6. 权限、数据安全和审计；
7. 异常、幂等、重试和可恢复性；
8. 性能和可扩展性是否有真实依据；
9. 测试覆盖和回滚方案；
10. 是否引入不必要复杂度。

输出：
- 必须修复的问题；
- 建议优化的问题；
- 可以接受的设计；
- 暂不建议建设的内容；
- 风险和决策建议。

每个结论尽量引用仓库中的文件路径、接口或测试证据。没有证据的内容标记为待确认。
